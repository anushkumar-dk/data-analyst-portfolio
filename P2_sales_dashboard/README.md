# Project 2: Interactive Sales Dashboard
**Problem:** A retailer wants sales, profit, top products and regional performance in one place.
**What I did:** One-page dashboard with 4 KPIs, monthly trend, top-5 products, sales by region and filters (year / region / category).
**Tools:** Python (pandas) for data prep, HTML + Chart.js for the dashboard. `sales_data.csv` can be loaded into Power BI / Tableau / Looker Studio to rebuild the same layout.
**Result:** Open `dashboard.html` in a browser. Data is synthetic.
